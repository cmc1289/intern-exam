# 入职考核系统

面向 Agent 实习生的入职能力测评工具，通过多模块题库 + AI 辅助评判，快速检验新人是否具备胜任工作的基本能力。

## 功能概览

- **多方向自选** — 开始考试前可选择 1~3 个专业方向（前端/后端/测试/运维/算法数据），系统按比例从对应题库抽题
- **客观题即时判定** — 单选、多选、判断题由后端直接比对答案
- **AI 批改主观题** — 接入 DeepSeek API，对简答题进行语义评判并给出评语
- **加权计分** — 不同难度题目有不同权重（简单×1.0 / 中等×1.5 / 困难×2.0）
- **分类统计** — 考试结束后展示总分、是否通过、各模块正确率、每题详情及答案解析
- **倒计时** — 30 分钟限时，剩余 5 分钟红色闪烁提醒

## 试卷结构

| 模块 | 题数 | 说明 |
|---|---|---|
| 通用基础（计算机网络 / 数据结构与算法 / 编程基础 / 操作系统） | 5 | 所有人必答 |
| 专业方向（自选 1~3 个） | 5 | 按比例从所选方向各抽 2~3 题 |
| Agent 岗位知识 | 3 | 必答 |
| 安全常识 | 2 | 必答 |
| **合计** | **15** | 其中至少 2 道主观题 |

题库总量约 90 道，按难度和模块均匀分布，不同方向选择下的期望总分差异 < 2%。

## 技术栈

- **后端**: Python + FastAPI + Uvicorn
- **前端**: 纯 HTML/CSS/JS（单页应用，无需构建）
- **AI 评判**: DeepSeek API（可选，未配置时使用关键词匹配兜底）

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API Key（可选，不配置则主观题用关键词匹配）
cp .env.example .env
# 编辑 .env，填入你的 DEEPSEEK_API_KEY

# 3. 启动
python main.py

# 4. 浏览器访问
# http://localhost:8000
```

## 题库格式

在 `question_bank.json` 中按以下格式增删题目：

```json
{
  "id": 唯一编号,
  "module": "通用基础 | 前端开发 | 后端开发 | 测试 | 运维 | 算法数据 | Agent岗位 | 安全常识",
  "category": "二级分类",
  "type": "single_choice | multi_choice | true_false | subjective",
  "difficulty": "简单 | 中等 | 困难",
  "weight": 1.0 | 1.5 | 2.0,
  "question": "题目文本",
  "options": ["选项A", "选项B", ...],   // 主观题不需要
  "answer": "正确答案 | [答案列表]",    // 多选用数组
  "explanation": "答案解析"
}
```

`exam_config` 可调整：随机抽题数、及格线、倒计时等。

## 答题流程

1. 首页 → 查看考试说明
2. 选择专业方向（1~3 个，也可跳过）
3. 30 分钟限时答题
4. 提交 → 展示成绩、分类统计、逐题解析
